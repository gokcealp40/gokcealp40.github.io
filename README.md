# pisagokce'nin kişisel sayfası

Bu site pisagokce'nin kişisel sayfasıdır. Adres: [https://gokcealp40.github.io](https://gokcealp40.github.io)

Kurulum yok. Program indirmene gerek yok. Sayfa düz HTML ve CSS dosyalarından oluşur.

## Yazıyı değiştirmek

Sitedeki cümleler `index.html` dosyasındadır.

1. `index.html` dosyasını bir metin editöründe aç.
2. Değiştirmek istediğin cümleyi bul.
3. Yenisini yaz ve kaydet.

Görünüm (renkler, boşluklar, yazı boyu) `styles.css` dosyasındadır. Yalnızca yazı değiştireceksen ona dokunma.

Fotoğraf veya iletişim eklemek istersen `index.html` içinde `<!--` ile başlayan Türkçe notlar var. Bu notlar sitede görünmez. Notun dediği yeri düzenlemen yeterli. E-posta, telefon veya adres yazmak zorunda değilsin.

## Oyunlar

Çarpım tablosu oyunları ayrı bir sayfadadır: `oyunlar/index.html`

Oradaki açıklama cümlelerini aynı şekilde, dosyayı açıp yazıyı bularak değiştirebilirsin. Oyunların kuralları `oyunlar/mantik.js` ve `oyunlar/oyun.js` içindedir. Yazı değiştirmek için bu iki dosyaya gerek yok.

Yıldızlar ve en iyi skorlar yalnız o anki tarayıcıda durur. Sunucuya gitmez. Başkası kendi cihazında kendi skorunu görür.

## Site nasıl yayınlanır?

Bu depo GitHub Pages sitesidir. `main` dalındaki dosyalar, derleme veya başka bir adım olmadan doğrudan yayınlanır.

Yaptığın değişiklik `main` dalına gelince (örneğin bir pull request birleşince) site birkaç dakika içinde [https://gokcealp40.github.io](https://gokcealp40.github.io) adresinde güncellenir.

Bilgisayarında denemek için `index.html` dosyasına çift tıkla. Tarayıcı sayfayı açar. Oyunlara geçmek için sayfadaki bağlantıyı kullan.
